# Depth-Aware Maize Disease Detection and Relative 3D Localization

Code, configurations and analysis scripts for the paper

> **Depth-Aware Maize Disease Detection and Relative 3D Localization Using YOLO11n and Depth Anything V2**
> Md. Sakhawat Hossain and Md. Saif Uddin
> *Journal of the Institution of Engineers, Bangladesh — Agricultural Engineering Division*
> Manuscript 31 AED 2024-2026

The pipeline pairs an **unmodified YOLO11n** detector with the **Depth Anything V2** monocular
depth model. Every detected disease region is placed in a relative 3D frame
(X<sub>rel</sub>, Y<sub>rel</sub>, Z<sub>rel</sub>) from a single RGB photograph — no depth sensor,
no stereo rig, no camera calibration.

Headline result on the held-out test split: **precision 0.852, recall 0.819, mAP@0.5 0.885,
mAP@0.5:0.95 0.691** across eight classes.

## Reproducing the results

```bash
git clone https://github.com/siam2461/maize-depth-aware-detection.git
cd maize-depth-aware-detection
pip install -r requirements.txt
```

**1. Train the detector** (or skip and use `weights/best.pt`)

```bash
python training/train_yolo11n.py --epochs 120 --seed 0 --pretrained
```

**2. Run the depth-fusion pipeline** — open
`pipeline/notebooks/02_relative_3d_localization_rerun.ipynb`, which loads `best.pt` from step 1.
It writes `results/3d_localization.csv`,
one row per detection with class, confidence, box, and X<sub>rel</sub> / Y<sub>rel</sub> /
Z<sub>rel</sub>.

**3. Reproduce the analyses**

```bash
python analysis/depth_stats.py          # Tables 5 and 6, Figure 9
python analysis/error_analysis.py       # Table 4
python analysis/failure_examples.py     # Figure 8
python analysis/timing_benchmark.py     # Table 9 timings
python analysis/external_validation.py  # Section 5.5
python analysis/we3ds_validation.py     # Section 4.3
```

Each script prints its numbers in the layout of the corresponding table, so they can be compared
against the paper line by line.

## A note on colour channels

Ultralytics assumes a NumPy image handed to `predict()` is in **BGR** order and flips it
internally. Passing an RGB array therefore feeds the detector channel-swapped images; the green
channel is unaffected, so healthy and downy-mildew detections inflate while rust, blight and gray
leaf spot collapse. The pipeline in this repository passes BGR throughout. Anyone adapting this
code should check the same thing.
